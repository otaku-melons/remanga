# exmanga
**exmanga** – это расширение для парсера [remanga](../../README.md), позволяющее получать главы с серверов [ExManga](https://exmanga.org) в случае невозможности их загрузки с оригинального сайта.

# Настройки
Данный раздел описывает специфичные для этого парсера настройки.
```JSON
"email": ""
```
Электронная почта для авторизации в [ExManga](https://exmanga.org).
___
```JSON
"password": ""
```
Пароль для авторизации в [ExManga](https://exmanga.org).
___
```JSON
"use_mirror": false
```
Указывает, нужно ли использовать зеркало _mirror.exmanga.org_ для выполнения запросов.
